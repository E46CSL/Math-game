
# 🎮 Math Mania

**Math Mania** is an interactive, web-based educational game designed to help young children build foundational math and clock-reading skills in a fun, visual, and engaging way!

---

## ✨ Features

* **Multiple Game Modes**:
* 🍎 **Count**: Practice counting objects with visual helpers.
* ➕ **Add**: Learn addition from basic counting to dragging & dropping numbers to match a target sum!
* ➖ **Minus**: Master simple subtraction with clear visual cross-outs.
* ✖️ **Times**: Multiples and early multiplication concepts.
* ➗ **Divide**: Visual grouping for basic division.
* 🔍 **Pattern**: Complete number sequences and find missing numbers.
* ⏰ **Clock**: Practice telling time on an interactive analog clock!


* **5 Progressive Difficulty Levels**:
* ⭐ **Beginner**: Numbers up to 10
* ⭐⭐ **Intermediate**: Numbers up to 20
* ⭐⭐⭐ **Advanced**: Numbers up to 50
* ⭐⭐⭐⭐ **Expert**: Numbers up to 100
* ⭐⭐⭐⭐⭐ **Master (Add Mode)**: Drag-and-drop 2-digit sum challenges (Target sums $\le 100$)


* **Child-Friendly & Interactive**:
* 🖐️ **Drag & Drop / Tap Support**: Optimized for desktop and mobile touch devices.
* 🔊 **Voice Support**: Text-to-speech built-in to read questions and feedback aloud.
* ⚙️ **Customizable Settings**: Toggle between Multiple Choice and Manual Typing modes, or adjust visual index displays.
* 📱 **PWA-Ready**: Fully responsive layout designed for mobile screens and tablets.



---

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Safari, Edge, Firefox).
3. Select a game mode and difficulty level to start playing!

---

## 🛠️ Built With

* **HTML5 / JavaScript (ES6)**
* **Tailwind CSS** (via CDN for styling)
* **HTML5 Canvas API** (for rendering analog clock visuals)
* **Web Speech API** (for voice readout)
